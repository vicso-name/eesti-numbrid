# 🇪🇪 Eesti Numbrid — Эстонские числа

Тренажёр эстонских чисел от 1 до 100.

**[▶ Играть](https://vicso-name.github.io/eesti-numbrid/)**

## Что тренируем

- **1–10:** üks, kaks, kolm, neli, viis, kuus, seitse, kaheksa, üheksa, kümme
- **11–19:** üksteist, kaksteist, kolmteist... üheksateist
- **Десятки:** kakskümmend, kolmkümmend... üheksakümmend, sada
- **Порядковые (1-10):** esimene, teine, kolmas... kümnes
- **Предложения:** Mul on kolm õuna, Mul on üks koer

## 5 типов упражнений

1. **Число → слово** — 7 → seitse (выбор из 4)
2. **Слово → число** — viis → 5 (выбор из 4)
3. **Собери предложение** — слова вразброс + обманки
4. **Напиши словом** — 12 → введи kaksteist
5. **Аудио-диктант** — послушай и напиши

## Фичи

- SM-2 Spaced Repetition
- Прогрессивная сложность (80% выбор → 70% ввод)
- Предгенерированные MP3 (Google Chirp3-HD)
- Авто-озвучка правильного ответа
- XP, уровни, daily streak, достижения
- Тепловая карта знаний
- PWA — устанавливается как приложение
- Offline-first
